# 课题组科研管理平台（grad-studio）

> 面向高校课题组的多角色科研协作管理平台（Electron + Vue 3 + MySQL）。
> 支持超级管理员 / 课题组管理员 / 导师 / 学生四类角色，前后端双重鉴权，菜单按角色动态渲染。

## 功能一览

**账号与权限**
- 登录 / 修改密码，密码加密存储（bcrypt）
- 超管管理平台账号，支持批量导入（CSV，可下载示例模板）
- 四角色动态菜单与操作鉴权

**课题组管理**
- 超管新建课题组并指定课题组管理员；组管可同时管理多个课题组
- 组管管理本组成员（导师 / 学生按身份自动归类），成员编辑、移除

**导师与学生**
- 导师绑定 / 解绑学生；学生个人资料展示所属课题组与指导老师

**科研业务**
- 学位节点管理：节点配置 + 学生学位记录
- 组会：创建、主持、汇报提交与点评
- 课题：课题建档、成员、负责人
- 任务：分配执行人、进展提交与更新
- 科研日志与周报（学生）：记录、提交、点评
- 科研成果：论文等成果登记与审核
- 文献库与文献笔记（学生）
- 科研档案（学生）
- 课题组知识库：知识条目 + 文件上传共享

**协作与运营**
- 课题组公告：发布、未读角标、阅读回执
- 站内消息：通知、已读管理
- 数据总览（超管）：按课题组 / 成员 / 用户 / 角色查看全平台数据，支持导出 CSV
- 全局搜索：按角色限定可见范围，点击结果直达对应页面
- 操作日志（超管）

**系统**
- 系统信息、数据库连接配置与切换、系统参数
- 检查更新：对比 GitHub Releases 版本，引导跳转下载

## 快速开始

```bash
npm install   # 安装依赖（首次）
npm run dev   # 开发模式（Vite + Electron）
npm run build # 构建前端
```

首次使用在登录页「添加数据库」填写 MySQL 连接信息，主进程自动建库建表并写入默认管理员
（`admin` / `admin123456`，首次登录强制改密）。

## 技术栈

| 层 | 技术 |
| --- | --- |
| 桌面壳 | Electron |
| 前端 | Vue 3 + Vue Router + Vite |
| 数据库 | MySQL 5.7+ / 8.x（mysql2，主进程直连，自动建库建表） |
| 安全 | bcryptjs、contextIsolation + 无 nodeIntegration |
